## 3. Top-21 BOSSNYUMBA-AHEAD-vs-LITFIN list (was 15, +6 added this round)

The May-18 list of 15 dimensions remains. The six added this round:

16. **Plan-and-Execute orchestration** — `packages/agent-platform/src/planning/` ships a planner→DAG-batcher→parallel-workers→verifier→re-planner loop with multi-LLM jury on each high-stakes decision. LITFIN runs sequential ReAct. 2026 benchmarks show 92% completion + 3.6× speedup over ReAct.
17. **Versioned AOP registry + canary bridge** — `packages/central-intelligence/src/agent/aops/` ships Decagon-style versioned prompts + regression-replay suite + auto-rollback hook into the existing canary controller. LITFIN has no versioned AOP discipline.
18. **Sleep-time consolidator (brain-evolution-worker)** — `services/brain-evolution-worker/` ships a Letta-style sleep-time worker (5 pipeline stages: read-traces → reflect → extract-deltas → write-memory → emit-report). Harvey reported 6× task-completion lift on this pattern. LITFIN has `consolidation-worker` analog but no sleep-time reflection.
19. **A2A v1.0 Agent Card + Ed25519 signed task lifecycle** — `packages/agent-platform/src/a2a/` ships Google's A2A protocol (Linux Foundation, 150+ orgs) end-to-end including `.well-known/agent.json` + sign/verify + state-machine + idempotent submit/get/cancel. LITFIN does not ship A2A.
20. **Multi-LLM Mixture-of-Agents fan-out synthesizer** — `packages/ai-copilot/src/providers/multi-llm-synthesizer.ts` ships MoA pattern (3 proposers + judge synthesizer, agreement metric via Jaccard, race-verify mode). LITFIN ships a router (pick-best-provider); BOSSNYUMBA ships both router AND fan-out.
21. **Reflexion CoT → next-turn system-prompt loop** — `packages/ai-copilot/src/reflexion/` ships distiller + LRU store + renderer with bounded token budget + tenant isolation. LITFIN's `learning-loop` doesn't render past lessons into the next system prompt.
